# Bullet Journal Minimalista - taskProject

Plantilla práctica para organizar tu semana, tareas, objetivos y hábitos.
Estilo: Minimalista, limpio, sin decoración innecesaria.
Formato: Listo para copiar en libreta física o Notion.

---

## PORTADA

```
═══════════════════════════════════════
            taskProject
     Bullet Journal - [Tu Nombre]
          [Año 20XX]
═══════════════════════════════════════

Reglas del sistema:
•  = Tarea pendiente
• X = Tarea completada
• > = Tarea migrada
• < = Tarea programada
• O = Evento
• - = Nota
• ! = Prioridad
• * = Inspiración/Idea

Índice → Página 2
```

## CÓMO USAR ESTE SISTEMA

### Reglas básicas:
1. **Escribe todo** - No confíes en la memoria
2. **Revisa cada mañana** - Planifica tu día en 5 minutos
3. **Revisa cada noche** - Marca completadas, migra el resto
4. **Sé realista** - 3-5 tareas por día máximo
5. **Usa signos** - Sistema de bullets para escanear rápido

### Flujo diario sugerido:
```
Mañana (5 min):
  └─ Revisar calendario → Elegir top 3 → Planificar bloques

Durante el día:
  └─ Capturar todo → Marcar completadas → Migrar si es necesario

Noche (5 min):
  └─ Revisar tareas → Preparar mañana → Actualizar tracker

Fin de semana (15 min):
  └─ Revisar semana → Planificar siguiente → Actualizar mensual
```
